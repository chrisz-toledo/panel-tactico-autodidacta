## 🧠 ESTRATEGIA DE PROMPTS MANUALES (Sin APIs de pago)

### Sistema de Prompts para Ollama Local

**1. Prompt de Planificación Diaria**
```
Eres mi tutor de programación. Hoy estoy estudiando [TEMA].

Contexto:
- Nivel actual: [principiante/intermedio/avanzado]
- Tiempo disponible: 1.5 horas
- Equipo: Mac M4 para teoria, HP Arch Linux para práctica

Genera:
1. Objetivo específico de hoy (SMART)
2. 3 recursos específicos de las 55 fuentes que debo consultar
3. Ejercicio práctico de 30 minutos
4. Criterio de "éxito" para la sesión
5. Pregunta de reflexión para el final

Responde en español, formato checklist.
```

**2. Prompt de Explicación Socrática**
```
Actúa como un profesor socrático estricto. No me des la respuesta directa.

Concepto que no entiendo: [CONCEPTO]

Guíame mediante preguntas hasta que yo mismo descubra la respuesta.
Si me equivoco, señala la falla lógica sin darme la solución.
Una vez que lo entienda, pídeme que explique el concepto con mis palabras.

Si explico correctamente, dame un ejemplo más complejo para validar.
```

**3. Prompt de Auditoría de Código (Sentinel)**
```
Eres un code reviewer senior de Google. Audita este código sin piedad:

```[LANGUAGe]
[PEGAR CÓDIGO]
```

Identifica:
1. Bugs potenciales (lógicos y de seguridad)
2. Violaciones de principios SOLID
3. Problemas de performance
4. Vulnerabilidades de seguridad (si aplica)
5. Sugerencias de refactorización

Formato: Bullet points por severidad (CRÍTICO/ALTO/MEDIO/BAJO)
```

**4. Prompt de Generación de Podcast de Estudio**
```
Genera un "guion de podcast" de 10 minutos para repasar:

Tema: [TEMA]
Nivel: [NIVEL]
Fuentes: [FUENTES ESPECÍFICAS DEL PLAN]

Estructura:
1. Introducción (1 min) - Gancho interesante
2. Concepto principal (4 min) - Explicación con analogía
3. Ejemplo práctico (3 min) - Caso real o código
4. Errores comunes (1 min) - Qué NO hacer
5. Takeaway final (1 min) - Frase memorable

Notas para que YO lo grabe y escuche mientras camino/conduzco.
```

**5. Prompt de Conexión de Conceptos**
```
Estoy aprendiendo [TEMA NUEVO]. 

Ya domino estos conceptos previos:
- [CONCEPTO 1]
- [CONCEPTO 2]
- [CONCEPTO 3]

Explica:
1. Cómo se relaciona el tema nuevo con cada concepto previo
2. Qué analogía une todos estos conceptos
3. Un proyecto mini que combine todo
4. El "por qué" de la conexión (qué principio subyacente los une)
```

**6. Prompt de Debugging Conceptual**
```
Tengo un error de comprensión. Mi intuición me dice [X], pero sé que está mal.

Explica el concepto de 3 formas diferentes:
1. Con analogía física/concreta
2. Con pseudocódigo paso a paso
3. Con diagrama/dibujo descrito en texto

Luego dame un problema similar pero diferente para verificar que entendí.
```

## 📅 CALENDARIO REALISTA (Adulto 30+, 15-20h/semana)

### Ritmo Sostenible

**Lunes a Viernes (1.5h/día):**
- 6:00-6:30 AM: Estudio teórico (video/lectura)
- 9:00-9:30 PM: Práctica hands-on
- Domingo: Revisión de la semana + planificación

**Sábado (5h):**
- 9:00 AM-2:00 PM: Bloque profundo para proyectos

**Domingo (2h o descanso):**
- Planificación de la semana siguiente
- Repaso ligero o podcast de estudio

### Reglas Anti-Burnout

1. **Stop-Loss de 25 min:** Si estás atascado >25 min, cambia de actividad
2. **Un día de descanso:** Domingo es sagrado (o sábado tarde)
3. **Vacaciones de estudio:** 1 semana cada 12 semanas de descanso total
4. **Revisión trimestral:** Cada 13 semanas, evalúa y ajusta el ritmo
