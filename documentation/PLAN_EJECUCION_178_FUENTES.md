## ⚠️ REGLAS ANTI-FRACASO

1. **Si no compiló, no cuenta** - Cada fuente debe terminar en código funcionando
2. **Un día sin código es un día perdido** - Mínimo 1 commit diario, aunque sea pequeño
3. **No copies sin entender** - Si usas StackOverflow/Copilot, explica en voz alta qué hace
4. **Documenta o muere** - Cada proyecto debe tener README + comentarios
5. **Enseña para consolidar** - Cada mes, explica un concepto a alguien (o graba video)
6. **Métricas brutales** - Trackear: horas reales, líneas de código, bugs resueltos

## 📅 HORARIO SEMANAL SUGERIDO (15-20 hrs)

### Ritmo Sostenible
- **12 semanas ON / 1 semana OFF** (ciclo)
- **Descanso activo:** Coding challenges ligeros en semana OFF
- **Vacaciones:** 2-3 semanas al año completamente OFF
