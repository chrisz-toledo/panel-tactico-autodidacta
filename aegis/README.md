# 🛡️ AEGIS — Sistema de Aprendizaje Autónomo

**Autonomous Educational Guidance & Intelligence System**

Sistema operativo de aprendizaje diseñado para autodidactas. Gestiona biblioteca de 69 fuentes educativas, genera prompts para IA (NotebookLM/Gemini), y gamifica el progreso de estudio.

## 🚀 CÓMO USAR

### Opción 1: Desde el Desktop (Recomendado)
1. Haz doble clic en **`🛡️ AEGIS V5.command`** en tu Desktop
2. Se abrirá en tu navegador predeterminado

### Opción 2: Desde la carpeta
1. Navega a `aegis/v5/launchers/`
2. Ejecuta `🛡️ AEGIS V5.command`
3. O abre directamente `v5/aegis-v5-BIBLIOTECA.html`

## ✨ CARACTERÍSTICAS DE V5.0

- **📚 Biblioteca de 69 Fuentes:** CS50, Python, Seguridad, IA/ML, Arquitectura, DevOps
- **🎧 AudioClase NotebookLM:** Genera podcasts diarios con analogías de vida real
- **🎯 Sistema SRS:** Repasos espaciados automáticos (1d, 3d, 7d, 14d, 30d)
- **⚡ Micro-Misiones:** Timers Pomodoro con persistencia de estado
- **🧠 Tutor Socrático:** Prompts para cuestionamiento guiado
- **🏆 Gamificación:** XP, streaks, achievements

---

## 🛠️ SISTEMA

- **100% Offline:** Funciona sin internet (salvo enlaces externos)
- **Single-File:** Toda la aplicación en un HTML
- **LocalStorage:** Datos guardados en tu navegador
- **Cross-Platform:** Funciona en Mac, Windows, Linux
