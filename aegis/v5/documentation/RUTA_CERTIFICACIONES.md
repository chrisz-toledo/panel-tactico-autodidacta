## 1. ESTRATEGIA GENERAL

### Principios de Certificación

1. **Demostrar, no solo tener:** Las certificaciones validan lo que ya sabes hacer
2. **Proyectos > Papel:** GitHub + proyectos reales > certificaciones
3. **Especialización:** Mejor ser experto en pocas que generalista en muchas
4. **ROI:** Calcular retorno de inversión antes de pagar

### Momentos para Certificarte

| Momento | Prioridad | Razón |
|---------|-----------|-------|
| **Buscando primer empleo** | Alta | Diferenciador en CV sin experiencia |
| **Transición de carrera** | Alta | Validar nuevas habilidades |
| **Trabajo remoto** | Media | Algunas empresas lo requieren |
| **Consultoría freelance** | Alta | Credibilidad ante clientes |
| **Ya empleado estable** | Baja | Experiencia vale más |

### Categorías de Certificaciones

| Icono | Categoría | Descripción |
|-------|-----------|-------------|
| 🆓 | **Gratuita** | Sin costo, validación de conocimiento |
| 💰 | **Low Cost** | <$100 USD, buen ROI |
| 💵 | **Mid Tier** | $100-500 USD, estándar de industria |
| 💎 | **Premium** | $500-2000 USD, alto reconocimiento |
| 🏴‍☠️ | **Elite** | >$2000 USD, especialistas confirmados |

## 2. CERTIFICACIONES GRATUITAS (FREE)

### 🐍 Programación y Desarrollo

#### **freeCodeCamp Certifications**
- **Costo:** FREE
- **Website:** freecodecamp.org
- **Disponibles:**
  - Responsive Web Design
  - JavaScript Algorithms and Data Structures
  - Front End Development Libraries
  - Data Visualization
  - Back End Development and APIs
  - Quality Assurance
  - Scientific Computing with Python
  - Data Analysis with Python
  - Information Security
  - Machine Learning with Python
- **Valor:** ⭐⭐⭐ (Reconocidas en industria, portfolio projects incluidos)
- **Tiempo:** 300h cada una (acumulativo)
- **Cómo obtener:** Completar curriculum online + 5 proyectos finales

#### **CS50 Certificate (Harvard)**
- **Costo:** FREE (o $199 por certificado verificado)
- **Website:** cs50.harvard.edu/x/2025/
- **Valor:** ⭐⭐⭐⭐ (Prestigio Harvard)
- **Tiempo:** 12-20 semanas
- **Cómo obtener:** Completar 9 problem sets + proyecto final + quiz

#### **Google IT Support Professional Certificate**
- **Costo:** FREE (con beca Coursera) o $39/mes
- **Website:** coursera.org/professional-certificates/google-it-support
- **Valor:** ⭐⭐⭐ (Google respalda, entry-level)
- **Tiempo:** 3-6 meses
- **Becas:** coursera.org/financial-aid (solicitar, siempre aprueban)

#### **AWS Cloud Practitioner**
- **Costo:** FREE (vouchers frecuentes)
- **Website:** aws.amazon.com/certification/certified-cloud-practitioner/
- **Valor:** ⭐⭐⭐ (Entry point a cloud)
- **Tiempo:** 2-4 semanas de estudio
- **Truco:** AWS ofrece vouchers gratuitos en eventos y retos

#### **Python Institute (PCEP, PCAP)**
- **Costo:** PCEP $59, PCAP $295 (pero vouchers gratuitos disponibles)
- **Website:** pythoninstitute.org
- **Valor:** ⭐⭐⭐ (Oficial de Python)
- **Vouchers gratuitos:** Cisco Networking Academy a veces ofrece exámenes gratis

### 🛡️ Ciberseguridad

#### **TryHackMe Pre-Security + Complete Beginner**
- **Costo:** FREE (paths gratuitos)
- **Website:** tryhackme.com
- **Valor:** ⭐⭐⭐ (Hands-on, muy práctico)
- **Tiempo:** 40-60 horas
- **Cómo obtener:** Completar rooms, no es certificado formal pero sí learning path

#### **HackTheBox CPTS (Certified Penetration Testing Specialist)**
- **Costo:** $199 (incluye examen + training)
- **Website:** academy.hackthebox.com/paths/jobrole/pentesting
- **Valor:** ⭐⭐⭐⭐ (Reconocido en pentesting)
- **Tiempo:** 3-6 meses
- **Nota:** Cuesta, pero es de las mejores inversiones para seguridad

#### **eJPT (eLearnSecurity Junior Penetration Tester)**
- **Costo:** $200 (incluye INE training)
- **Website:** elearnsecurity.com
- **Valor:** ⭐⭐⭐⭐ (Hands-on, sin tiempo límite)
- **Tiempo:** 40-80 horas de estudio
- **Diferencial:** Examen take-home, no presión de tiempo

#### **PortSwigger Web Security Academy Certifications**
- **Costo:** FREE
- **Website:** portswigger.net/web-security/certification
- **Valor:** ⭐⭐⭐ (Especialización web security)
- **Tiempo:** Variable según nivel
- **Requisito:** Completar todos los labs de una categoría

#### **TCM Security PJPT**
- **Costo:** $199
- **Website:** tcm-sec.com
- **Valor:** ⭐⭐⭐⭐ (Práctico, no tiempo límite)
- **Tiempo:** 40 horas de curso + examen take-home
- **Bueno para:** Principiantes en pentesting

### 🐧 Linux y Sistemas

#### **Linux Foundation LFCS / LFCE**
- **Costo:** $395 (pero descuentos frecuentes al 50%)
- **Website:** training.linuxfoundation.org/certification
- **Valor:** ⭐⭐⭐⭐ (Estándar de industria Linux)
- **Tiempo:** 2-3 meses
- **Vouchers:** Buscar en Linux Foundation newsletter

#### **LPI (Linux Professional Institute)**
- **Costo:** LPIC-1 ~$200
- **Website:** lpi.org
- **Valor:** ⭐⭐⭐ (Reconocimiento internacional)

### 🌐 Networking

#### **Cisco Networking Academy**
- **Costo:** FREE (cursos), CCNA $300
- **Website:** netacad.com
- **Valor:** ⭐⭐⭐⭐⭐ (CCNA es estándar dorado)
- **Ruta:** Networking Essentials (free) → CCNA
- **Truco:** Muchos community colleges ofrecen Cisco gratis

### Estrategia de Estudio

**Método de 3 Pasos:**

1. **Video Course (40%)**
   - 1.5x speed mínimo
   - Tomar notas en Obsidian
   - Practicar comandos en tiempo real

2. **Hands-On (40%)**
   - Crear proyectos paralelos
   - Labs, labs, labs
   - Documentar todo en GitHub

3. **Practice Exams (20%)**
   - Mínimo 3 exámenes de práctica
   - 85%+ antes de examen real
   - Repasar respuestas incorrectas

**Timeline Tipo:**

```
Semana 1-4:   Video course + labs iniciales
Semana 5-8:   Proyectos propios + documentación
Semana 9-10:  Practice exams + weak areas
Semana 11:    Review final + otro practice exam
Semana 12:    EXAMEN OFICIAL
```
