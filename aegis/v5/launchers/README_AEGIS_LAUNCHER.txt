🛡️  AEGIS v5.0 — LANZADORES DISPONIBLES
═══════════════════════════════════════════════════════════

Tienes 5 opciones para abrir AEGIS v5.0. Elige la que prefieras:

┌─────────────────────────────────────────────────────────────┐
│ 1️⃣  ABRIR_AEGIS_V5.command                                  │
│     → DOBLE CLICK (Opción recomendada)                      │
│     → Abre Terminal + Navegador automáticamente             │
│     → Actualizar: F5 en navegador                           │
│     → Ideal para: Usuarios finales                          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 2️⃣  VS Code + Live Server (Mejor para desarrollo)          │
│     → Instalar extensión "Live Server" en VS Code          │
│     → Click derecho → "Open with Live Server"              │
│     → Actualizar: AUTOMÁTICO al guardar (Cmd+S)            │
│     → Ideal para: Modificar código frecuentemente          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 3️⃣  AEGIS_V5_Simple.sh                                      │
│     → Ejecutar en Terminal: ./AEGIS_V5_Simple.sh             │
│     → Servidor Python simple en puerto 8080                 │
│     → Actualizar: F5 en navegador                           │
│     → Ideal para: Sin instalar extensiones                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 4️⃣  AEGIS_V5_LiveServer.py                                  │
│     → Requiere: pip3 install watchdog                        │
│     → Auto-reload con detección de cambios                   │
│     → Más avanzado, requiere Python watchdog                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 5️⃣  AEGIS_V5_Launcher.scpt                                  │
│     → AppleScript (abrir con Script Editor)                 │
│     → Guardar como "Aplicación" para ícono en Dock          │
│     → Interfaz nativa de macOS                               │
└─────────────────────────────────────────────────────────────┘
