## 📦 ¿Qué es AEGIS v6.0?

AEGIS (*Autonomous Educational Guidance & Intelligence System*) es un **dojo digital personal** diseñado para llevar a un autodidacta de **cero a nivel mundial** en programación, ciberseguridad e IA.

No es un gestor de tareas. Es un sistema de **entrenamiento militar académico** que:
- Elimina la fatiga de decisión (*qué estudiar* → ya está decidido)
- Previene el falso positivo de competencia (*proof of work* obligatorio)
- Evita el burnout (ritmo circadiano adaptativo + stop-loss)

## 🎮 Flujo de Uso Diario

### 1. Abrir AEGIS v6-BETTER
```bash
open aegis/v6-BETTER/aegis-v6-BIBLIOTECA.html
```

### 2. Reportar Energía (Ritmo Circadiano)
- Usa el slider 1-10 para reportar tu energía actual
- El sistema sugiere fuentes según tu cronotipo + hora del día

### 3. Seleccionar Fuente
- Clic en cualquier fuente del grid
- Se resalta en verde y muestra detalles

### 4. Generar Prompt
- Click "🧠 Tutor Socrático" u otro generador
- Copia el prompt generado
- Pégalo en NotebookLM o Gemini

### 5. Iniciar Misión (Pomodoro)
- Click "🎯 25 min Lectura" (o práctica/código)
- Timer corre con barra de progreso
- Al completar: +XP, +progreso de fuente

### 6. Proof of Work (Anti-Falso-Positivo)
Antes de marcar completada:
- Explica el concepto como a un niño de 12 años
- Escribe pseudocódigo o caso práctico
- Conecta con otros temas

### 7. Exportar Backup
```javascript
// En consola (F12):
AEGIS_V6.exportDataV6()
```
